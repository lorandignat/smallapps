# Developer journal

Append-only, newest at the bottom. One entry per task attempt — including failed
attempts. This is how the next developer invocation avoids repeating a mistake.

Format:

```md
## YYYY-MM-DD — TASK-### (attempt n)
- changed: files
- approach: 1-2 lines
- checks run: commands + result
- surprises / gotchas:
- for the tester:
```
